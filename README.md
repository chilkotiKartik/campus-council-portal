## 📌 Project Overview

A dedicated governance portal facilitating student union elections, budget transparency reports, club funding approvals, and campus town hall scheduling.

---

## 🚀 Key Features

- **Budget Transparency:** Open ledgers detailing student activity fee allocations.
- **Club Proposals:** Standardized workflows for student event permits and club charters.

## 🚦 Getting Started

### 1. Clone the Repository
`ash
git clone https://github.com/chilkotiKartik/campus-council-portal.git
cd campus-council-portal
`

### 2. Install Dependencies
`ash
npm install
`

### 3. Run Development Server
`ash
npm run dev
`

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
